\section{Formal Verification and Test Contracts}
\label{app:lean}

\textbf{Status (June 2026).}  Machine-checked Lean~4 proofs were developed in
a separate formal-verification workflow (Aristotle / Mathlib) and are listed in
\texttt{paper/lean/README.md} as the target artifact set
(\texttt{VariationalWarmstart.lean}, \texttt{ShadowEstimator.lean},
\texttt{AdaptiveAllocation.lean}, \texttt{HierarchicalComplexity.lean},
\texttt{QOSExtensions.lean}, \texttt{PhaseTimeBound.lean}).  Those \texttt{.lean}
files are \emph{not} yet committed to this repository; this appendix records
their intended scope rather than claiming they compile here.

\paragraph{Executable verification in this repository.}
Every theorem and algorithm in the main text is instead pinned by a
\textbf{numerical property test} in \texttt{tests/} and a \textbf{standalone
reproduction script} in \texttt{scripts/verify\_*.py}.  The mapping is
documented in \texttt{TRACEABILITY.md} at the repository root.  Key contracts:
\begin{itemize}
  \item Adaptive oracle: support error $\leq \varepsilon$ at documented $M$;
        off-support entries exactly $1$ (\texttt{tests/test\_adaptive\_boolean.py}).
  \item Hierarchical sketch: monotone sample reduction in $k$
        (\texttt{tests/test\_hierarchical\_sketch.py}).
  \item Variational warmstart: proxy loss decreases; full-budget convergence
        below $\varepsilon$ on K-sparse inputs
        (\texttt{tests/test\_warmstart\_e2e.py}).
  \item Interferometric shadow: empirical error within the $O(\sqrt{s/T})$ envelope
        (\texttt{tests/test\_interferometric\_shadow.py}).
  \item TVD metrics: raw-L1 vs.\ Hadamard-induced definitions pinned separately
        (\texttt{tests/test\_tvd\_core.py}).
\end{itemize}

\paragraph{Roadmap.}  Committing the Lean sources and a \texttt{lake build} CI
step remains on the assembly checklist (\texttt{paper/ASSEMBLY\_CHECKLIST.md}).
